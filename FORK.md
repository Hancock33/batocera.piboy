# How this fork differs from upstream

This is a fork of [batocera-linux/batocera.linux](https://github.com/batocera-linux/batocera.linux).
This file records what is different, so an upstream merge conflict can be
resolved by looking it up here.

## Scope

- Two images are built and supported: `piboy4` (Raspberry Pi 4 in a PiBoy DMG)
  and `x86_64`. `x86_wow64` and `aarch32-subsystem` only build the 32-bit
  libraries those two images embed.
- Every other upstream board config lives in `configs/unsupported/`. Their
  `board/batocera/<vendor>` trees are kept so merges stay clean, but the
  packages that only they use are not sourced from the top-level `Config.in`.
- The `buildroot` submodule points at
  [Hancock33/buildroot](https://github.com/Hancock33/buildroot).

## Deliberate differences

Add a line here whenever a change is made that upstream would not make.

- `piboy4` builds its kernel from the `bcm2712` defconfig plus the fragments
  listed in `configs/batocera-piboy4.board`.
- `x86_64` builds a CachyOS kernel with the full config in
  `board/batocera/x86/linux_x86_64-defconfig.config`.
- `piboy4` ships PiBoy emulator defaults from
  `python-src/batocera-launch/resources/defaults/config-piboy4.yml`.

## Keeping this file and the tree honest

- `scripts/build/fork_delta.py` rewrites the generated section below. Run it
  after merging upstream; it compares with the last merged upstream commit
  (`--tip` compares with `upstream/master` itself, to preview a merge).
- `scripts/linux/sparse-checkout.sh` leaves the unsupported board trees out of
  a build checkout.
